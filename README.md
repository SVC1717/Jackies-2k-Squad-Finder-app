# Jackie's 2K Squad Finder

A mobile-friendly NBA 2K community web app.

Included:
- Squad Finder for Rec, 2s, 3s, 5s and Pro-Am
- Jackie's Build Vault
- Community build submissions
- Jackie's Approved badge
- Squad challenges
- Player stats
- Demo Admin / Co-Admin controls
- Local browser storage so added players/builds remain on that device

## Open locally
Double-click `index.html`.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Open Settings → Pages.
4. Choose `Deploy from a branch`.
5. Select `main` and `/(root)`.
6. Save.

## Important
This regenerated version is a working front-end demo. Real multi-user sign-in, shared data, image uploads, and private admin roles will require connecting Firebase.
